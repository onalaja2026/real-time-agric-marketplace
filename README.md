# Real-Time Agricultural Marketplace

Design and evaluation of a real-time web-based agricultural marketplace 

## Overview
Connecting smallholder farmers directly to buyers, eliminating middlemen, real-time price updates.

## Tech Stack
- Backend: PHP, MySQL
- Frontend: HTML, CSS, JavaScript (AJAX for real-time)
- Payment: Paystack API
- Real-time: WebSockets / AJAX Polling

## Features
- Farmer/Buyer role-based login
- Real-time product listing & pricing
- Cart & Paystack checkout
- Order tracking
- Chat system

## Research Contribution
Evaluates impact of real-time technology on agricultural supply chain efficiency in Nigeria.
